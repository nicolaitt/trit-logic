Data 2026-09-26 - Simbolo terzo = 0 con 1 dentro = ①

SIMBOLI UFFICIALI DEFINITIVI
0 = ovale vuoto = Bianco = Spento = 0 fisso SENZA cerchio esterno
1 = con baffetto = Nero = Acceso = 1 fisso SENZA cerchio esterno
Terzo = 0 con 1 dentro con baffetto = cerchio che contiene 1 = Grigio = Casualità
Unicode comodo: ① = 0 con 1 dentro. Il carattere provvisorio precedente è eliminato.

FUNZIONE
① da solo = casuale
① + 0 = ①
① + 1 = 1   (1 domina in OR)
① · 0 = 0   (0 blocca in AND)
① · 1 = ①
NOT: ¬0=1  ¬1=0  ¬①=①
